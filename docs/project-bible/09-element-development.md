# 09 — Разработка элементов истории

**Версия:** 1.0  
**Статус:** ACTIVE  
**Ответственность модуля:** определить единый порядок разработки любого элемента истории до написания его окончательного текста.

---

## 1. Назначение

Любой значимый элемент истории (персонаж, объект, локация, тема, событие или сцена) сначала анализируется, а затем описывается.

Текст не должен становиться отправной точкой разработки.

---

## 2. Область применения

Модуль применяется при разработке:

- персонажей;
- ключевых объектов;
- локаций;
- сцен;
- сюжетных событий;
- тем и символов.

---

## 3. Последовательность разработки

Каждый элемент проходит пять обязательных этапов:

1. Определить функцию элемента в истории.
2. Определить информацию, которую должен получить зритель.
3. Определить причину существования элемента именно в таком виде.
4. Определить будущий конфликт, изменение или испытание элемента.
5. Найти визуальный способ показать всё перечисленное, а не сообщать словами.

Переход к написанию окончательного текста допускается только после прохождения всех этапов.

---

## 4. Приоритет визуального решения

Если информация может быть передана действием, поведением, окружением или изображением, такой способ предпочтительнее прямого текстового объяснения.
